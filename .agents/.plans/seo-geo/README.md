## Scope rationale

The repository already has the major technical SEO/GEO foundation: canonical
SEO context, comparison Article JSON-LD, source links, sitemap generation,
social cards, IndexNow, permissive crawler directives, and generated
`llms.txt`/`llms-full.txt`. This batch repairs the verified freshness defect and
connects the existing comparison corpus to the LLM discovery surface. It gives
first-class placement to the existing VS pages for virtua (~892k weekly
downloads), TanStack Virtual (~61k), and the dormant legacy Svelte package
(~36k). It does not create duplicate routes or redesign infrastructure that is
already functioning.
